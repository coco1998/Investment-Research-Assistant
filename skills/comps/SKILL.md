# 可比公司估值 Skill

## 在体系中的位置

本 Skill 是 VC 投研 Agent 体系的**子模块**，可独立触发，也可被 `financial-model` 嵌入调用（**必须**）。

**两种触发场景**：

| | 场景一：fin-mod 内嵌调用 | 场景二：独立触发 |
|---|---|---|
| **触发方** | fin-mod（必须调用）| 用户直接指定 |
| **前置检查** | fin-mod 已检查 ind-res + comp-res 是否都做了（如缺一告知用户）| 无强制前置 |
| **可比公司来源** | comps 从 ind-res/comp-res 中抽象出行业赛道 → 自行搜索可比上市公司 → 列表请用户确认 | ① 用户给公司名/名单 → 直接拉数 ② 用户说「做 XX 行业的可比公司」→ 简要搜索 → 列表请用户确认 |

- **前置依赖**：`wind-mcp-skill`（唯一数据源，拉取 A 股/港股/美股行情和财务数据）；场景一由 fin-mod 传入行业赛道信息（fin-mod 负责检查 ind-res/comp-res 是否就绪）
- **下游消费**：→ `financial-model`（退出估值倍数输入）
- **输出目录与文件命名**：独立模式 → `可比估值/[主题或公司名]/`；嵌入 fin-mod（项目内）→ 本地 `[项目名]/财务/可比估值_v[N].md`

## 角色

服务于 VC 投资团队的**估值对标分析师**。核心任务：给定一组可比公司，拉取实时市场数据和财务数据，输出结构化可比估值表，回答「这个赛道/公司值什么倍数」。

## 使用场景

| 模式 | 触发信号 | 产出 |
|------|---------|------|
| **指定公司** | 「拉 柏楚电子 凯尔达 汇川技术 的估值倍数」 | 可比估值表 + 筛选说明 |
| **指定赛道** | 「拉 AI 焊接赛道的可比估值」「具身智能可比公司有哪些」 | 赛道可比公司发现 + 估值表 |
| **混合模式** | 给出部分公司 + 赛道关键词，补充更多 | 名单扩展 + 估值表 |

默认模式为**指定公司**。

## 核心原则

**1. 数据源唯一性**。唯一数据源为 Wind（通过 `wind-mcp-skill`），不通过 WebSearch 抓取第三方网站的估值数据。

**2. 先确认，再拉数**。候选可比公司列表必须先展示给用户确认（含选择理由），确认后再调用 Wind。

**3. 按指标独立剔除，非按公司整体剔除**。PE<0（亏损）→ 该公司 PE 不入均值，但 PS 仍可参与；PE>200x → PE 不入均值；PS>100x → PS 不入均值。被剔除公司仍在表中保留但标红。直接同行即使 PE>100x 也可酌情保留参考，在备注中说明。

**4. 中位数优先**。对标参考值优先用中位数（MEDIAN），平均数（AVERAGE）作为交叉参考。中位数更稳健，不受极端值影响。

**5. 退出倍数向下取整**。保守原则——如可比 PE 中位数 ~41x，退出年取 40x；如 ~18.5x，取 18x。

**6. 估值方法匹配盈利状态**。有稳定净利润（净利率>5% 且为正）→ PE 估值为主、PS 为辅；无净利润/亏损 → PS 估值为主；重资产行业补充 EV/EBITDA。

**7. 退出年倍数递减**。退出年更远 → 规模更大增速更低 → 倍数更低。如可比 2026E PE 中位数 ~41x，2030E 取 25x。

**8. 表格规范**。所有估值倍数带「x」后缀（12.5x）。市值用亿元/亿美元并标注币种。字段为空标注「—」。

## 工作流程

### 第〇步：确定范围

0.1 与用户确认模式（指定公司 / 指定赛道 / 混合）

0.2 指定公司模式：用户给股票代码或公司名 → 直接进入第一步
指定赛道模式：先发现可比公司 → 展示确认 → 再拉数
混合模式：用户给一部分 + 赛道搜索补充

0.3 如嵌入 fin-mod 调用：从 ind-res/comp-res 产出中提取候选可比公司列表，展示给用户确认

---

### 第一步：构建可比公司名单

**指定赛道模式**：
- 从 ind-res 产出中提取可比公司线索（如 ind-res 未做，做简要搜索）
- WebSearch `[赛道关键词] 上市公司 / A股/港股/美股`
- 每个候选标注：代码 + 公司名 + 选择理由（业务相似度/竞争关系/阶段相似度）
- 列表展示给用户确认（见交互确认）

**交互确认（强制）**：
向用户展示候选可比公司表格：

| 代码 | 公司名 | 市场 | 选择理由 |
|------|------|------|------|
| 688188.SH | 柏楚电子 | A股 | 激光切割控制系统，相似客户群 |
| ... | ... | ... | ... |

提问：「这些可否作为可比公司？有没有需要补充或剔除的？」

---

### 第二步：拉取 Wind 数据

用户确认后，通过 `wind-mcp-skill` 拉取数据：

**a) 市场数据**（并行调用所有公司）：
```bash
node scripts/cli.mjs call stock_data get_stock_price_indicators \
  '{"windcode":"688188.SH","indexes":"中文简称,最新成交价,总市值1,总股本,市盈率(TTM)"}'
```
国际公司用 `global_stock_data`。

需要字段：`中文简称,最新成交价,总市值1,总股本,市盈率(TTM),52周最高,52周最低`

**b) 历史财务 + 一致预期**（并行调用所有公司）：
```bash
node scripts/cli.mjs call analytics_data get_financial_data \
  '{"question":"[公司名1] [公司名2] 的最近3年营业收入和归母净利润以及一致预期未来2-3年营业收入和归母净利润","lang":"中文"}'
```

---

### 第三步：数据整理与筛选

3.1 整理数据：
- 各公司市值、各年收入、各年净利润
- 计算 PS(TTM)、PE(TTM)、各前瞻年 PS/PE

3.2 筛选规则：
- PE(TTM) < 0 → PE 列标注「亏损，不参与统计」
- PE(TTM) > 200x → PE 列标注「>200x 剔除」
- PS(TTM) > 100x → PS 列标注「>100x 剔除」
- 剔除后公司仍在表中保留，**标红底色**并注明剔除原因

3.3 计算参考倍数：
- 中位数（MEDIAN）+ 平均数（AVERAGE）
- 被剔除公司不纳入统计

| ... | | | | | | | | | | |

**统计行**：

| 统计 | PS(TTM) | PE(TTM) | PS(2026E) | PE(2026E) | PS(2027E) | PE(2027E) |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 中位数 | XXx | XXx | XXx | XXx | XXx | XXx |
| 平均数 | XXx | XXx | XXx | XXx | XXx | XXx |
| 样本数 | N | N | N | N | N | N |

如样本 < 3，中位数和平均数均不计算，标注「样本不足（N<3），不建议对标」。

---

### 第五步：退出倍数建议

如有净利润：
- 退出 PE = 可比前瞻年 PE 中位数（向下取整）
- 退出 PS = 可比前瞻年 PS 中位数（交叉参考）

如无净利润：退出 PS = 可比前瞻年 PS 中位数（向下取整）

逐年递减规则：退出年距当前越远，倍数越低（增速衰减逻辑）。

向用户确认采用的退出倍数（如在 fin-mod 嵌入模式下，此步由 fin-mod 的交互点 C 处理）。
