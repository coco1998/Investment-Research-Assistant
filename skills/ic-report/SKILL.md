# 投决报告 Skill

## 角色

**叙事构建者，不是模板填充器。** 上游 Skill 产出提供素材——投决报告的任务是把素材组织成一个「IC 读完之后无法 dismiss」的故事。核心判据：**如果 IC 看完只记住一堆数字，报告失败了。如果 IC 看完能用一句话转述「为什么投这家公司」，报告成功了。**

## 前置依赖

pre-judge + industry-research + tech-research + company-research（全部 C 级必须）。competitor-analysis + financial-model 缺失时可标注但不阻断。

## 五个叙事原则

### 1. 开篇即 stakes

第一页不是项目概览表。第一页是一个判断句——这件事为什么重要、为什么是现在、为什么是我们。概览表放到后面。

❌ 「示例公司是某硬件厂商，估值合理，建议立项。」
✅ 「一个新硬件品类能不能普及，卡在核心部件的成本、体验和供应链。主流路线有三重约束，标的选择了另一条可能破局的路线，而且已经拿到早期量产证据。」

### 2. 每个关键选择画二分法

不要罗列「行业有 XXX 条技术路线」。画出两条路——我们选哪条、为什么、选错了会怎样。IC 需要在「战场地图」上看到我方位置。

格式：`路线 A（主流/成熟/大厂选） vs 路线 B（少数/早期/我们选）`。对比维度：当前份额、核心优势、核心劣势、代表公司、为什么大厂选 A、为什么我们选 B、如果 B 错了会输给 A 吗。

### 3. 供应链是护城河叙事，不是供应商列表

不写「供应商：XX 公司，供应 YY 产品」。写「这个供应商怎么被我们绑定的」——什么关系、什么利益安排、什么独供条款、什么共同投入。供应链深度 = 客户切换成本 = 护城河。

### 4. 风险是最狠的话自己先说

每条风险第一句是 IC 心里最想问但不好意思问的。用事实+律师意见（如有）+风险等级+应对。不写「市场竞争加剧风险」这种 IC 看完无感的泛化表述。

### 5. 每个数字讲一个商业故事

不给孤立的数字。BOM 成本→渠道出货价→终端售价→渠道利润→渠道商动力。这是一个逻辑链。读者顺着数字就能理解「为什么能卖出去」。

## 输出结构（10 节，顺序和传统模板不同）

```markdown
# [公司] 投资决策报告 v[N]

> 版本说明：基于哪些上游报告+新增材料

## 1. 投资主题
（1 页。一句话 stakes + 两段因果链。先写赛道为什么是必争之地，再写我们为什么是稀缺标的。末尾附「一句话电梯演讲」——30秒版本。）

## 2. 投资亮点
（1 页，3-5 条。全报告写完之后最后提炼的核心。每条格式：**punchy 判断** + 2-3 句证据。写完测试：读给不知道项目的人听，能复述 3 条以上→通过。**不是「团队强/市场大/技术好」——是具体到「为什么这条赛道没有这个标的就玩不转」。**）

## 3. 投资风险
（1 页，3-5 条。IC 最担心但不好意思问的话，你替他说出来。每条格式：
- 风险描述（最坏的结局是什么）
- 发生概率+判断依据
- 为什么还能投（不是在说「风险可控」，是在说「即使这个风险发生了，downside 是什么、为什么还能接受」）
- 应对/监控手段

**强制**：每条风险须与 §2 投资亮点一一对应——最大的风险对应最核心的投资假设。哪条投资逻辑最脆弱→对应哪个风险最致命。）

## 4. 战场地图
（2-3 页。行业路线二分法+公司解法 vs 行业痛点对比表。IC 读完要知道「战场长什么样、我们站在哪」。

**强制表格——真壁垒 vs 假短板**：

| 竞对 | 标的相对竞对的独占能力 | 归因（技术难/战略选择） | 护城河强度 | 竞对补上需多久 |
|------|------|:---:|:---:|:---:|

归因判断：竞对缺失的功能，其已有能力是否能复用延伸？能→战略选择（随时可补）。不能且有具体技术原因→真壁垒。）

## 5. 产品 & 供应链
（3-4 页。产品迭代路线图（含季度节点）+供应链绑定叙事+成本拆解。不是「我们有这些供应商」——是「这些供应商被我们这样绑定」。供应链关系表：供应商/供应什么/关系类型（独供/利益绑定/共同投入）/排他条款/切换成本。）

## 6. 商业验证
（2-3 页。客户 pipeline 表+渠道打法+盈利模型。客户表强制：客户/场景/进展/收入预期/怎么拿下/为什么选我们/切换成本/落地时间。每家客户≥1行。）

## 7. 团队
（1-2 页。不是履历表——是「为什么是这个人+这个团队」。创始人的经历弧线：从哪来→经历过什么→为什么是唯一能做这件事的人。核心成员每人不超 2 行，只写「不可替代性」。**强制**：能力互补矩阵表——维度/创始人/联合创始人/空白（谁都没覆盖的能力）。）

## 8. 财务 & 估值
（2 页。年度预测表+可比估值（引用 comps）+退出路径（≥2条）。缺失数据标注 [待公司提供]。）

## 9. 下一步尽调
（0.5-1 页。P0 行动清单——不是「建议做 X」，是「如果不做 X，我们无法判断 Y」。P0/P1 分级。≥5条。）

## 10. 项目概览
（1 页。纯表格，放最后——服务流程，不是判断。快照表：团队/赛道/技术/商业/融资各一行+关键数据一行。）
```

## 质量自检

- [ ] IC 看完第一页，能用一句话转述「为什么投这家公司」？
- [ ] 至少 2 个二分法对比（技术路线/产品定位/商业模式）？
- [ ] 「真壁垒 vs 假短板」表每行有归因判断（技术难 vs 战略选择）？
- [ ] 供应链叙事是否点名了具体关系（独供/利益绑定/共同投入）？
- [ ] 风险第一条是不是 IC 心里最想问但不好意思问的？
- [ ] 每条风险是否与 §2 投资亮点对应（最大的风险=最核心假设的反面）？
- [ ] 有没有至少一条数字逻辑链（不是孤立数字）？
- [ ] 团队部分有能力互补矩阵表+空白标注？
- [ ] 下一步尽调是「不做X就无法判断Y」格式？
- [ ] 每一节读完后，IC 是「知道了」还是「被说服了」？
