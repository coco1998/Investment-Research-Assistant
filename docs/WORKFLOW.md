# 工作流

## 1. 新项目

- 在 `workspace/projects/[项目名]/materials/` 放入 BP、Datapack、访谈原文和参考资料。
- 创建或更新 `workspace/projects/[项目名]/master.md`。
- 调用 `/pre-judge` 形成初筛判断。

## 2. 深入研究

推荐顺序：

```text
Ingest → 初筛 → 行业研究 → 技术研读 → 竞品对标 → 公司深度 → 管访清单/专家访谈 → 投决报告
```

每一步都应读取已有报告和会议记录，避免重复研究。

## 3. 跨项目沉淀

具有复用价值的行业框架、公司实体、技术路线和专家观点，应写入 `workspace/knowledge/2_wiki/`。
